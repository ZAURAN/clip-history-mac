# История буфера для macOS

Аналог Win+V из Windows: приложение живёт в строке меню, запоминает всё, что вы копируете, и по сочетанию клавиш показывает список рядом с курсором.

## Возможности

- Запоминает текст, картинки, скриншоты и файлы (последние 100 записей, история сохраняется после перезагрузки).
- **⌘⇧V** — открыть историю. Стрелки + Enter, клик или ⌘1…⌘9 — вставить. Поиск по тексту.
- **⇧↩** — вставить текст без форматирования, **⌘⌫** — удалить запись, **Esc** — закрыть.
- Новые скриншоты (⇧⌘3 / ⇧⌘4) сами попадают в историю; по желанию — сразу и в буфер, как Win+Shift+S.
- Пароли из менеджеров паролей не запоминаются.
- В меню: выбор сочетания клавиш (⌘⇧V, ⌥V, ⌃V, ⌘⌥V), автозапуск, пауза, очистка истории.

## Установка

1. Скачайте `ClipHistory-*.dmg` со страницы [Releases](https://github.com/ZAURAN/clip-history-mac/releases/latest).
2. Откройте его и перетащите «История буфера» на папку «Программы».
3. Запустите приложение из «Программ».

Работает на macOS 14 и новее, на Mac с Apple Silicon и Intel.

**Если macOS пишет, что приложение не удаётся проверить.** Приложение бесплатное и не подписано платным сертификатом Apple. Нажмите «Готово», откройте Системные настройки → Конфиденциальность и безопасность и внизу нажмите «Всё равно открыть» у «История буфера». Это нужно один раз.

## Сборка из исходников

Нужны инструменты командной строки Xcode (`xcode-select --install`).

```bash
./build.sh --install   # собрать и установить в ~/Applications
./build.sh --dmg       # собрать установщик build/ClipHistory-<версия>.dmg
```

## Разрешения

- **Универсальный доступ** — чтобы выбранный элемент сразу вставлялся. Без него элемент просто попадает в буфер, вставить можно через ⌘V. Если в окне истории видна оранжевая кнопка «⚠︎ Включить автовставку» — разрешение не выдано.
- **Доступ к Рабочему столу** — чтобы видеть новые скриншоты.

После пересборки macOS может считать приложение новым: тогда удалите старую запись в «Универсальном доступе» кнопкой «−» и включите заново.

## Где хранятся данные

`~/Library/Application Support/ClipHistory/`
